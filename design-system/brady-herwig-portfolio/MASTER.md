# Design System Master File

**Project:** Brady Herwig Portfolio  
**Updated:** 2026-07-30  
**Style:** AuthKit — frosted glass cathedral at midnight  
**Theme:** Dark  

## Palette

| Token | Value | Role |
|-------|-------|------|
| Midnight Canvas | `#05060f` | Page background |
| Frost Glow | `#d1e4fa` | Body / default text |
| Ice Highlight | `#d8ecf8` → `#98c0ef` | Display gradient headings |
| Moon Mist | `#c7d3ea` | Muted body |
| Fog Veil | `#9da7ba` | Helper text |
| Void Violet | `#663af3` | Primary CTA only |
| Glass edge | `rgba(186,215,247,0.12)` | Inset hairlines |

## Type

- **UI/body:** Inter (Untitled Sans sub) 400–600  
- **Display:** Space Grotesk (aeonikPro sub) 500  
- **Eyebrows:** JetBrains Mono (dotDigital sub) 15px, 0.1em tracking  

## Surfaces

Frosted glass cards (`rgba(186,214,247,0.03)` + inset glow stack). Deep glass modals for education/contact. Blueprint grid + conic halo ambient layers.

## Radii

Buttons 999px · Cards 16px · Badges 6px · Icon circles 9999px  

## Do

- Violet only for primary CTAs  
- Inset frost edges, not solid borders  
- Centered section eyebrows with fading rules  
- Generous section spacing (~120px)  

## Don't

- No Henry monochrome / ASCII / parchment  
- No extra chromatic accents beyond violet CTA  
- No bold display type (use weight 500)
