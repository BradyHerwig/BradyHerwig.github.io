---

## Purpose

Dedicated page for curated project deep-dives. Home may teaser one project; full write-ups live here.

Each project section includes:

1. Title + short summary  
2. Screenshot carousel (`.shot-carousel` left ↔ right)  
3. **What it shows** — product / analysis narrative  
4. **What I learned** — skills & takeaways  
5. **Tools & libraries** — exact stack used  

---

## Layout

1. Top ticker banner + sticky nav (Projects link active via scale)  
2. Masthead display hero — Fraunces title with italic inline phrase  
3. Stamped Ink masthead (`CASES` / Manuka substitute)  
4. Jump links (outlined 12px tags) when showcases exist  
5. Stacked project case studies (`#project-*`) on Paper  
6. Inverted editorial letter CTA at bottom  
7. Coordinate footer  

**Spacing:** Master section padding; card padding 16–24px.  
**Radius:** 12px on UI; square corners on screenshot frames.  
**Screenshots:** grayscale filter for monochrome cohesion.

- Use Ink/Paper inversion for emphasis, never a blue CTA
